# Callejero de Medina del Campo · atribución y licencia

`medina-callejero.json` es una instantánea de las vías con nombre de Medina del Campo obtenida de
**OpenStreetMap**: nombre, tipo de vía y geometría.

- Datos © colaboradores de OpenStreetMap. Disponibles bajo la **Open Database License (ODbL) 1.0**:
  https://www.openstreetmap.org/copyright
- La instantánea es una base de datos derivada. Si se redistribuye, debe mantenerse bajo ODbL y con
  esta atribución.
- El bloque `__fuente` del archivo indica el servidor, la fecha de los datos OSM, la consulta y el
  SHA-256 de las vías.

Lo único real en la demostración de ULIT Censo es la cartografía. Los establecimientos, sus cifras,
sus números de portal y sus ubicaciones son **ficticios**: no son direcciones comprobadas.

Para regenerarla: `npm run callejero` (véase el README del proyecto).
